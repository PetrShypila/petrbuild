# Petr Build

One-page site for **Petr Build**, the residential remodeling GC of Puget Premier LLC (Seattle).

## Run in VS Code

1. Clone this repo and open the folder in VS Code (or Cursor).
2. Open `index.html`.
3. Preview it:
   - **Live Server** extension: right-click `index.html` → Open with Live Server
   - or in the terminal: `python3 -m http.server 8080` then open http://127.0.0.1:8080

Opening the file with a plain `file://` tab also works; a local server is cleaner.
